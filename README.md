  🚌 Bus Pass System

A web-based    Bus Pass System    built using    Python ,    HTML ,    CSS ,    JavaScript , and    SQLite .    Admins can manage users, routes, and issue passes efficiently.

---

   🔧 Tech Stack

-    Frontend   : HTML, CSS, JavaScript  
-    Backend   : Python (Django)  
-    Database   : SQLite  

---

   📌 Features


    🛠️ Admin Panel:
- Admin login
- Dashboard, category, Pass, Queries, Search, Report, Change Pasword.
- Add/edit/delete bus routes and schedules
